# Repository instructions

This repository contains the source for two production static websites. Before
changing site content, deployment configuration, DNS, TLS, Nginx, or the
production server, read `.codex/DEPLOYMENT.md` in full.

The default publication target is the owner's ECS, not GitHub Pages. Do not
publish to `unclevan.github.io` or push this repository merely as a deployment
step unless the user explicitly asks for that destination or push.

Never store passwords, private keys, API tokens, certificate private keys, or
other credentials in this repository.
